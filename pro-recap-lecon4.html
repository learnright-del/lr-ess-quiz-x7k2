📊

Les 4 Conditionnels · En un coup d'œil

Formule + type + exemple

0
Vérité générale
If + présent simple → présent simple
If you heat ice, it melts.
1
Futur possible
If + présent simple → will + inf.
If it rains, I'll stay home.
2
Hypothèse présente
If + prétérit → would + inf.
If I had time, I would travel.
3
Regret / passé irréel
If + past perfect → would have + PP
If I'd studied, I'd have passed.
⚠️ Règle d'or : jamais de "will" ou "would" dans la clause IF ! · Unless = If not · Were pour toutes les personnes au cond. 2 (formel)
💭

I Wish / If Only

Souhaits et regrets

Souhait présent
I wish + prétérit
I wish I spoke Italian.
Regret passé
I wish + past perfect
I wish I had studied harder.
If only (insistance)
If only + prétérit/past perf.
If only I had more time!
Même structure que Cond. 2 & 3
Wish présent ≈ Cond. 2 · Wish passé ≈ Cond. 3
🔧

Phrases Types · Key Sentences

Les essentielles de la leçon 4 Professional

If you mix red and blue, you get purple. (Cond. 0)
Si tu mélanges rouge et bleu, tu obtiens du violet.
If it rains tomorrow, we'll cancel the picnic. (Cond. 1)
S'il pleut demain, on annulera le pique-nique.
If I were you, I wouldn't say that. (Cond. 2)
À ta place, je ne dirais pas ça.
If I had known, I would have helped you! (Cond. 3)
Si j'avais su, je t'aurais aidé(e) !
I wish I could speak Japanese. (souhait présent)
J'aimerais parler japonais.
Unless she arrives soon, we'll start without her.
À moins qu'elle n'arrive bientôt, on commencera sans elle.
💬

Dialogue · À savoir par cœur

Entretien professionnel — les 4 conditionnels

👔
If you join our team, what will you bring?
Si vous rejoignez notre équipe, qu'apporterez-vous ?
👩
If I join, I'll bring five years of international experience.
Si je rejoins, j'apporterai cinq ans d'expérience internationale.
👔
If you were the manager, what would you change first?
Si vous étiez le/la responsable, que changeriez-vous en premier ?
👩
If I had started learning English earlier, I would have had more opportunities — but every experience has brought me here!
Si j'avais commencé plus tôt, j'aurais eu plus d'opportunités — mais chaque expérience m'a amenée ici !
✅

Ce que vous savez faire · What you can do

Vos acquis après la leçon 4 Professional

  • ✓
    Utiliser le conditionnel 0 pour les vérités générales et habitudes
  • ✓
    Utiliser le conditionnel 1 pour les situations futures réalistes
  • ✓
    Utiliser le conditionnel 2 pour les hypothèses présentes irréelles
  • ✓
    Utiliser le conditionnel 3 pour les regrets et situations passées irréelles
  • ✓
    Exprimer souhaits et regrets avec I wish / If only
  • ✓
    Utiliser unless, as long as et provided that comme variantes de if

📝 Devoir · Homework

  • 1
    Écrivez 8 phrases conditionnelles — 2 de chaque type (0, 1, 2, 3).
  • 2
    Écrivez 4 phrases avec I wish / If only — 2 souhaits présents et 2 regrets passés.
  • 3
    Reprenez le dialogue de l'entretien professionnel et apprenez-le — puis adaptez-le à votre propre situation professionnelle !
  • 4
    Bonus : Notez 3 regrets ou rêves dans votre vie en anglais avec le bon conditionnel — un vrai exercice de réflexion personnelle ! 😊
