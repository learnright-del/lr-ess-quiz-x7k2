Question Tags

Phrase positive → tag négatif · Phrase négative → tag positif

⚡ Règle : on reprend l'auxiliaire de la phrase (be/have/will/modal...) — s'il n'y en a pas, on utilise do/does/did.
You're coming to the meeting,
aren't you?
She has sent the report,
hasn't she?
We haven't missed the deadline,
have we?
They won't be late,
will they?
Let's get started,
shall we?
I'm leading this project,
aren't I?

Phrases Types · Key Sentences

Les essentielles de la leçon 9

We need to roll out the new system across all offices by Q3.
Nous devons déployer le nouveau système dans tous les bureaux d'ici le T3.
The project exceeded all expectations — we're very pleased with the results.
Le projet a dépassé toutes les attentes — nous sommes très satisfaits des résultats.
You've signed off on the new budget, haven't you?
Vous avez approuvé le nouveau budget, non ?
Let's get the ball rolling — we've been putting this off long enough.
Lançons les choses — on a assez repoussé ça.
I'll touch base with the client this afternoon to keep them in the loop.
Je prendrai contact avec le client cet après-midi pour le tenir informé.
We need to iron out a few issues before we can scale up production.
Nous devons résoudre quelques problèmes avant de pouvoir monter en puissance.
