Conditionnels Mixtes — 2 Types

Mélange de temps entre la condition et le résultat

Type 1 — Passé → Présent : If + past perfect → would + base (conséquence présente d'une condition passée)
Exemple : "If she had studied medicine, she would be a doctor now." (mais elle ne l'est pas)
Type 2 — Présent → Passé : If + prétérit → would have + PP (conséquence passée d'une condition présente)
Exemple : "If he were more organised, he would have finished the report on time."
Différence clé : Type 1 = condition passée manquée · Type 2 = trait présent + conséquence passée
🎩

Inversions Hypothétiques — sans IF

Were / Had / Should + sujet = style formel C1-C2

Were + sujet + to : "Were the board to approve this, implementation could begin immediately."
Had + sujet + PP : "Had we anticipated this, the outcome would have been entirely different."
Should + sujet : "Should you require further information, please do not hesitate to contact us."
Were it not for : "Were it not for the economic downturn, growth would have been exceptional."
But for : "But for your timely intervention, the situation would have escalated."

Phrases Types · Key Sentences

Les essentielles de la leçon 7 Mastery

Had I known about the merger, I would not be in this position today.
Si j'avais su pour la fusion, je ne serais pas dans cette position aujourd'hui.
Were the company to invest now, it would reap the benefits for years to come.
Si l'entreprise investissait maintenant, elle en récolterait les bénéfices pendant des années.
But for her intervention, the project would have collapsed entirely.
Sans son intervention, le projet se serait entièrement effondré.
Supposing we had acted sooner — the outcome might have been very different.
En supposant que nous ayons agi plus tôt — le résultat aurait pu être très différent.
Had they followed the protocol, we would not be facing this crisis now.
S'ils avaient suivi le protocole, nous ne ferions pas face à cette crise maintenant.
Were it not for the team's resilience, the entire initiative would have failed.
N'eût été la résilience de l'équipe, l'initiative entière aurait échoué.
